## 📋 Prompt Writing Best Practices

### ✅ DO's

1. **Be Specific with Dimensions**
   - Use exact measurements: "5m × 4m" not "medium sized"
   - Specify units clearly: "200mm" or "0.2m" for walls
   
2. **Explicitly State Enclosure**
   - Always mention: "All walls must connect to form fully enclosed rooms"
   - Add: "No open wall endpoints"

3. **Provide Complete Specifications**
   - Room dimensions
   - Wall thickness
   - Door/window sizes
   - Clear spatial relationships

4. **Use Standard Measurements**
   - Walls: 200mm (exterior), 150mm (interior)
   - Doors: 900mm standard, 1200mm main entrance
   - Windows: 1500mm × 1200mm typical
   - Floor height: 3000mm standard

5. **Specify Layout Logic**
   - "Living room near entrance"
   - "Kitchen adjacent to living room"
   - "Bedrooms in private zone"

### ❌ DON'Ts

1. **Don't Be Vague**
   - ❌ "3 bedrooms and a kitchen"
   - ✅ "3 bedrooms (master: 5m × 4m, bedroom 2: 4m × 4m, bedroom 3: 4m × 3.5m)"

2. **Don't Use Ambiguous Units**
   - ❌ "0.2mm thick walls"
   - ✅ "200mm thick walls"

3. **Don't Forget Connections**
   - ❌ Just list rooms
   - ✅ Specify how rooms connect and relate

4. **Don't Overcrowd**
   - Make sure total room area < plot area
   - Leave 20-30% for corridors and walls

5. **Don't Skip Details**
   - Include door widths
   - Include window placements
   - Specify wall heights

## 🔧 Troubleshooting Guide

### Problem: "Wall has unusually thin thickness: 0.2mm"

**Cause:** Unit confusion - system interpreted "0.2" as millimeters

**Solution:**
```
Change: "walls 0.2m thick"
To: "walls 200mm thick"
OR: "exterior walls: 200mm thickness"
```

### Problem: "Found 2 open wall endpoints - walls may not form closed boundaries"

**Cause:** Rooms aren't fully enclosed

**Solution:**
Add to prompt:
```
CRITICAL: All walls must connect to form fully enclosed rooms with no open endpoints. 
Each room must be completely surrounded by walls with proper corner connections.
```

### Problem: DXF Export Button Shows Error

**Cause:** Missing or invalid geometry data

**Solutions:**
1. Use complete prompt templates above
2. Wait for "Design generated successfully" message
3. Check for validation warnings first
4. Try exporting SVG first to verify geometry exists

### Problem: Rooms Don't Fit in Plot

**Cause:** Room dimensions too large for plot size

**Solution:**
```
1. Calculate total room area
2. Add 30% for walls and corridors  
3. Ensure total < plot area
4. Reduce individual room sizes if needed
```
